# Tokens

The design system is MUI 7 plus the theme in `src/theme.ts`. Every value on this page is read from that file, so it cannot drift from the code. Components read from the theme (palette, spacing, shape, typography) instead of hardcoding values.

The same tokens are Figma variables in the [Pantry Shifts Figma file](https://www.figma.com/design/IPcWrmWuclsYviyq4sJ5NS/Design-Lab-X-AI?node-id=0-1): collections `Tokens`, `Palette`, `Spacing`, `Shape` and `Typography`, each with a single `Default` mode because the code has no themes.

## Color tokens

The `tokens` object in `src/theme.ts`. In components use the palette key, not the hex value and not the `tokens` object.

## Typography

Font family: <code>{theme.typography.fontFamily}</code>. Inter 400, 500, 600 and 700 are loaded from Google Fonts.

The theme sets `h1`, `h2`, `h3` and `button`. The other variants used in the code (`body1`, `body2`, `caption`) are MUI defaults.
